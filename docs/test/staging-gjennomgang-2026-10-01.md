Alvorlighet: **H** = blokkerer en brukeroppgave · **M** = feil eller misvisende, men kan omgås · **L** = kosmetisk eller forbedring

## Sammendrag

Ingen H-funn. Alle hovedflyter kan fullføres. De viktigste funnene:

1. **Varselet «favoritt solgt» vises aldri i appen** (#1), selv om innstillingen er på.
2. **Uendelig oppdateringsløkke i React** (#2) ved KI-utfylling i «Ny annonse».
3. **Tomme samtaler** (#3): de opprettes før første melding, teller som ulest og foreslår «Merk som solgt».
4. **Horisontal scroll på mobil** i «Mine annonser» (#4).
5. **Manglende bilder i R2 på staging** (#5).

## Testet uten funn

- **Forside:** hero, kategorier, «Nye annonser»-karusell. Kaupet-kode (gyldig → annonse, ugyldig → «Fant ikke annonsen»). 404-side.
- **Søk:** fritekst, fjerne chip, sortering (pris lav → høy), prisfilter fra/til (oppdaterer URL), visning av ønskes kjøpt-fane.
- **Lagre søk:** dialog, navn, «Mine søk»-liste. Varsel ved ny matchende annonse, og klikk på varsel åpner annonsen og teller ned.
- **Favoritter:** legge til (toast), liste, prisfall-varsel «−50 % · 200 kr → 100 kr».
- **Ny annonse:** opplasting av 2 bilder, forhåndsvisning, KI-tittel/kategori (Turnstile OK i Chrome), validering av beskrivelse, tilstand, pris, levering, postnummer → sted og kart, se over, publiser (lapp med Kaupet-kode og QR).
- **Redigering:** inline pris (lagres), meny med «Merk som solgt / Avpubliser / Slett».
- **Ønskes kjøpt:** 5-stegsflyt, kategoriforslag, matchvarsel, publisering, synlig for andre i søk.
- **Meldinger:** tekst med æøå og emoji, bildevedlegg, lesekvittering «Lest», menyen Blokker / Rapporter (ikke utført).
- **Salg:** «Merk som solgt» fra chat → bekreft kjøper → «Solgt»-merke på annonsen, salgsteller 1. Gjensidig vurdering (selger → kjøper og kjøper → selger), som vises på /bruker/:id.
- **Profil:** profilinfo, varslingsinnstillinger (push/e-post per type), kontoside (e-post, passord og slett konto vises, men ble ikke utført).
- **Juridisk:** /vilkar og /personvern lastes.
- **Konsoll:** ingen andre feil enn #2.
